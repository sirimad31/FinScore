# FinScore – Financial Health Score Calculator

FinScore is a web-based project designed to help users understand their financial health through a simple scoring system.

## Features
- Financial health score calculation
- Expense and savings assessment
- Debt and investment analysis
- Simple and user-friendly interface

## Technologies Used
- HTML
- CSS
- JavaScript


## Purpose
To help users evaluate their financial habits and understand areas where they can improve their financial well-being.

## Project Type
Academic Mini Project
